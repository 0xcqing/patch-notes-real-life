A single-line changelog entry for a bug in human biology: the 3:58 a.m.
rumination loop that reopens an argument everyone else has forgotten.

The entry:

    v3.4.0: fixed a bug where the brain wakes the body at 3:58 a.m. to reopen a 2016 argument nobody else remembers.

## What it fixes

The 3.4.0 release patches an involuntary nocturnal wake-up that reopens a
long-closed social conflict, with no one else affected.

## Run

    node main.ts

Writes `entry.txt` (the line plus a trailing newline) to
`$MAKEFUN_OUTPUT_DIR`, or to `/output` when unset. No dependencies.
